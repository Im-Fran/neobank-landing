# [Neobank](https://neobank.franciscosolis.cl)
Una landing page para un neobanco ficticio.

# Instalación
1. Clona el repositorio:
```bash
git clone https://github.com/Im-Fran/landing-neobank.git
```
   
2. Navega al directorio del proyecto:
```bash
cd landing-neobank
```

3. Instala las dependencias:
```bash
bun install
```

4. Inicia el servidor de desarrollo:
```bash
bun dev
```

# Descripción
Esta es una landing page para un neobanco ficticio, creada con Bun y Tailwind CSS. El proyecto incluye una estructura básica de HTML y CSS, y está diseñado para ser responsive.

# Características
- Diseño responsive
- Uso de Tailwind CSS para estilos
- Estructura modular con componentes reutilizables
- Optimización para SEO básica
- Soporte para múltiples navegadores
- Accesibilidad mejorada
- Documentación clara y concisa
